# Proyecto_DFIR

Proyecto realizado para la práctica de Digital Forensics (DFIR) de KeepCoding.

## Contenido

- Análisis forense de un sistema Windows.
- Investigación de evidencias e indicadores de actividad sospechosa.
- Adquisición y análisis de memoria RAM.
- Uso de Volatility para el análisis de memoria.
- Estudio de metadatos en imágenes enviadas por diferentes plataformas.

## Herramientas

- Volatility
- ExifTool
- Herramientas DFIR de Windows
